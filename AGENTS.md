# Repository maintenance

- The installable package is `skills/precision-skill/`. Its `SKILL.md` routes tasks to focused English references and the offline comparators/validator. New artifact tools require NumPy; the legacy target-score comparator is standard-library-only. Repository regression tests live in `tests/`.
- Maintain `README.md` in English and `README.zh-CN.md` in Chinese with matching scope. Keep skill instructions, technical references, code documentation, and maintenance instructions in English. Follow the [Agent Skills specification](https://agentskills.io/specification).
- Private `projects/<project>/environments/` directories own reusable environment declarations. Each case's manifests reference its declarations separately from actual execution evidence.
- Cases own contracts, manifests, a current guide, a work log, dedicated collectors/tests, and `runs/`. Work records belong to the case; tool tests and actual device execution are separate evidence.
- Keep case-specific code with the case. Move genuinely shared code to the project or framework as reuse warrants. Create directories when they have content.
- Run directories use `<side>-<task>-<UTC YYYYmmddTHHMMSSZ>`, with side `gpu`, `npu`, or `compare`. Create them exclusively. Runs hold artifacts and logs rather than copies of case guides.
- Keep models, source data, and installed environments at their resource locations. Preserve historical run bytes and internal paths. When an old run lacks a reliable start time, use `<side>-<task>-migrated-<UTC migration timestamp>` and document the mapping; the timestamp denotes migration. Save new validation results in a new run.
- Follow [workflow](skills/precision-skill/references/workflow.md) for execution scope and decisions. Confirm the intended approach before edits and change at most three files per batch. For a bug fix, first reproduce it temporarily, retain a meaningful regression test, and remove the temporary reproducer. Preserve permanent tests.
- Run `python -B -m unittest discover -s tests -v` from the repository root. Validate skill metadata, local links/anchors, and changed script behavior. A self-comparison does not establish cross-device agreement.
