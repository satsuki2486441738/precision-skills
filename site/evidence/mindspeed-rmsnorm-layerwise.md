# RMSNorm 修复：层间采样与同输入反向重放

本轮沿用已验证的 MindSpeed zero-centered gamma 修复，继续定位剩余梯度差异。模型为 Qwen3.5-9B-Base，Megatron Bridge 0.4.2、Megatron Core 0.17.1。GPU 使用 NVIDIA H200 与 Transformer Engine 2.11.0；NPU 使用 Ascend 910C 与原历史 MindSpeed 提交及已记录的本地修复。

## 过程

1. 两端各完成一次 TP4 整模型前向和反向，采集最终 `decoder.final_layernorm` 的输入、输出、传入梯度、输入梯度、gamma 和参数梯度。
2. 新 action scores 与 objective 精确复现各侧前次记录。两端 gamma 初值相同。GPU 参数梯度精确复现；NPU 新旧捕获最大差异为 1.19e-7。
3. 使用独立 FP64 RMSNorm 公式及解析导数重算；解析导数已经过独立 PyTorch FP64 autograd 验证。
4. 将两端各自采到的同一份输入、gamma 和传入梯度，分别交给两侧原生 RMSNorm 重放，共完成四个组合。输入形状为 `[95, 2, 4096]`，保留 BF16 存储、zero-centered gamma 和 epsilon=1e-6。

## 结果

| 实验条件 | 参数梯度跨端 RMSE | 最大绝对差异 |
| --- | ---: | ---: |
| 原整模型边界，各侧使用各自输入 | 6.284117298085227e-5 | 0.0013427734375 |
| 同一份 GPU 输入和传入梯度 | 0 | 0 |
| 同一份 NPU 输入和传入梯度 | 1.862645149230957e-9 | 1.1920928955078125e-7 |

在原整模型边界，输入激活 RMSE 已为 0.050187378548939614，传入梯度 RMSE 已为 4.158046679294606e-6。对各侧输入做独立 FP64 计算，参数梯度的跨端 RMSE 为 6.262616945525806e-5，接近实际观测。

这支持将最终 RMSNorm 参数梯度差异主要归因于其输入和传入梯度；首个上游差异算子尚未定位。本轮未确认第二项独立库缺陷。

同输入前向 RMSE 为 0.006347622254109395 / 0.006432420031900642，输入梯度 RMSE 为 1.4015400661365647e-7 / 1.3931282707584265e-7（分别对应 GPU / NPU 捕获输入）。这些原生计算差异保留为观测，尚未归因为新的缺陷。验收结论由用户判断。
