# 首次投影选择性 FP32：原模型验证

2026-10-21 · Qwen3.5-9B-Base · NVIDIA H200 TP4，复用 Ascend 910C 留存参照。

只替换第 0 层 GDN 输入投影的前向 GEMM：BF16 归一化输入和权重转 FP32 计算，再存回 BF16。保留原生 TE 归一化、保存的 BF16 操作数、TP4 通信和反向。每个 rank 仅命中一次；离开目标前向后立即恢复原调度函数。没有优化器更新。

## 原任务结果

两条固定 completion、32 个 action scores；rank 0 的 33 个对应边界，最终归一化层全部 4 个 rank。

| 与保留 NPU 观测的差异 | 原生 GPU 对照 | 选择性 FP32 GPU |
| --- | ---: | ---: |
| 首次投影输出 RMSE | 0.000423104 | 0.000141163 |
| 第 31 层输出 RMSE | 0.0501874 | 0.0496412 |
| Action logprob RMSE | 0.0419924 | 0.0217032 |
| Action logprob 最大绝对差异 | 0.113272 | 0.0953732 |
| NLL 绝对差异（nat/token） | 0.000416219 | 0.00332671 |
| GRPO objective 绝对差异 | 0.0110621 | 0.00449923 |
| 最终 norm 参数梯度 RMSE（rank 0） | 0.0000628412 | 0.0000358140 |

GPU NLL 从 1.433662951 变为 1.430752456；留存 NPU NLL 为 1.434079170。逐 token 差异变小不保证均值差异变小。这里比较的是两种实现的观测，NPU 输出不作为数学真值。

结论：保留当前默认策略。该候选改善局部投影和部分整模型差异，但 NLL 差异增大，尚未形成统一改善，也没有确认第二个库语义 bug。

## 反向隔离与原生复跑

固定同一输入、权重和传入梯度的原生 TE 重放中，输入梯度、gamma 梯度及完整 12,648,448 个权重梯度逐值一致；覆盖融合/非融合权重梯度两种模式。候选前向逐值复现此前独立 FP32 GEMM。

完全不加载适配器、沿用原入口复跑时，所有前向边界、scores、objective 和 logits hash 均逐值一致，但第 0 层输出梯度对历史原生运行的 RMSE 为 8.844e-6。采用相同作用域的原生策略对照为 8.878e-6；两次新原生执行互比为 8.889e-6。重复运行差异已存在于原生执行，底层原因尚未定位；一次候选运行不能给出统计置信结论。

首版适配器的调度包装持续整个任务，作用域过宽；已通过函数身份回归收窄至目标实例的前向，退出和异常均恢复原函数。旧运行保留，最终指标使用修正后的对照与候选。

本地 TP 权重分片、训练模式和 autograd 前向；每模式预热 3 次，交替配对测量 20 次。以下是带采样代码的中位耗时，包含 Python 发射间隙和转换，不是纯 kernel 时间，也不包含 TP 通信与反向。
